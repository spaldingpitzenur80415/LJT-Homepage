# LJT-Homepage

Personal academic homepage of **Junteng Liu**, first-year PhD candidate at the HKUST NLP Group, Hong Kong University of Science and Technology (HKUST).

The site is built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template, which is a fork of [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes-jekyll-theme/).

## Site content

| Path | Content |
| ---- | ------- |
| `_config.yml` | Site-wide settings and the sidebar author profile: name, bio, affiliation, email, GitHub, Google Scholar and X (Twitter) |
| `_data/navigation.yml` | Header menu: About, Publications |
| `_data/authors.yml` | Author metadata |
| `_pages/about.md` | Front page: biography, research interests, education, research experience, publications, honors and awards, skills, contact information |
| `_pages/publications.html` | Publications page, generated from the `_publications` collection |
| `_publications/` | One Markdown file per publication (preprints and conference papers) |

## Deployment

The site is built with Jekyll and deployed to GitHub Pages by `.github/workflows/jekyll.yml` on every push to `master`.
